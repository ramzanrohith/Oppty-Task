ANIMATIONS

CSS Animation is a CSS feature used to add movement and visual effects to HTML elements without using JavaScript.

Key Frames

@keyframes is a CSS rule used to define the different stages (frames) of an animation. It specifies how an element's styles should change from the beginning to the end of the animation.

Exact definition: @keyframes is a CSS rule that defines the different steps or stages of an animation.
Types of Keyframes
There are two common ways to define keyframes:

Using from and to :
from represents the starting state (0%).
to represents the ending state (100%).

Animation Examples

FADE

Makes the element appear gradually.

ROTATE

Rotates the element in a circle.

BOUNCE

Makes the element jump up and down.

SLIDE

Moves the element from left to right.

SCALE

Enlarges the element smoothly.

SKEW

Tilts the element by changing its angle.
